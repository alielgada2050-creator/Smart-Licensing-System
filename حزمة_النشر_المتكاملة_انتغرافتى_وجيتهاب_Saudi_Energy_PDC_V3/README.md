### 3. خطوات النشر على GitHub والتشغيل الفوري (Deployment Guide)
1. **إنشاء مستودع جديد على GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Saudi Energy & PDC Smart Permit System V3"
   git branch -M main
   git remote add origin https://github.com/<YOUR_USERNAME>/saudi-energy-smart-permits.git
   git push -u origin main
   ```
2. **النشر التلقائي على GitHub Pages**:
   - توجه إلى إعدادات المستودع (`Settings -> Pages`)، واختر المصدر (`GitHub Actions`).
   - سيعمل ملف سير العمل `.github/workflows/deploy.yml` فورياً لنشر الموقع مجاناً برابط مباشر.
3. **التشغيل المحلي عبر Docker**:
   ```bash
   docker-compose up --build -d
   ```
   - المتصفح: `http://localhost`
   - الـ API: `http://localhost:8000/docs`
